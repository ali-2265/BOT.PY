# ربات پست‌گذار کانال تلگرام

این ربات به شما امکان می‌دهد تا با استفاده از یک ربات تلگرام، متن‌های خود را در کانال `@BI_GH_AM` با یک دکمه شیشه‌ای مخصوص منتشر کنید.

### امکانات

- ارسال متن به کانال با هدر اختصاصی
- نمایش متن اصلی با کلیک روی دکمه شیشه‌ای
- سیستم احراز هویت کاربران
- بررسی خودکار ادمین بودن ربات
- دیتابیس SQLite برای ذخیره‌سازی اطلاعات
- مدیریت کامل خطاها

### پیش‌نیازها

- Python 3.8 یا بالاتر
- یک ربات تلگرام با توکن معتبر
- دسترسی ادمین به کانال `@BI_GH_AM`

1. **کلون کردن یا دانلود پروژه**
